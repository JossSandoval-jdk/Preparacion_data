# Preparación de Datos

Repositorio correspondiente a la fase de **preparación y procesamiento de datos** del proyecto.

## 📌 Descripción

En esta fase se realizan las actividades necesarias para transformar los datos originales en un conjunto de datos limpio, consistente y adecuado para su posterior análisis y entrenamiento de modelos de Machine Learning.

## 🔄 Proceso de preparación

Las principales actividades realizadas son:

1. **Carga de los datos**

   * Importación de los datos provenientes de las fuentes disponibles.
   * Revisión de la estructura y tipos de datos.

2. **Exploración de los datos**

   * Análisis de dimensiones.
   * Identificación de variables.
   * Revisión de valores faltantes y duplicados.
   * Análisis de la distribución de los datos.

3. **Limpieza de datos**

   * Tratamiento de valores nulos.
   * Eliminación o tratamiento de registros duplicados.
   * Corrección de inconsistencias.
   * Estandarización de formatos.

4. **Tratamiento de valores atípicos**

   * Identificación de observaciones que presentan comportamientos inusuales.
   * Evaluación de los valores atípicos antes de decidir su tratamiento.

5. **Transformación de datos**

   * Conversión de tipos de datos.
   * Codificación de variables categóricas cuando corresponde.
   * Normalización o estandarización de variables numéricas cuando es necesario.

6. **Generación del dataset final**

   * Validación de la calidad de los datos.
   * Exportación del conjunto de datos preparado para las siguientes etapas del proyecto.

## 🛠️ Tecnologías utilizadas

* Scikit-learn

## ⚙️ Instalación

Clonar el repositorio:

```bash
git clone https://github.com/JossSandoval-jdk/Preparacion_data.git
```

Ingresar al proyecto:

```bash
cd Preparacion_data
```

Instalar las dependencias:

```bash
pip install -r requirements.txt
```

## ▶️ Ejecución

Si el proyecto utiliza notebooks, iniciar Jupyter:

```bash
jupyter notebook
```

Posteriormente, abrir el notebook ubicado en:

```text
notebooks/
```

y ejecutar las celdas en orden.
